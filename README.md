# AI_project
**Asteroid Detection using Machine Learning**  
This project is a web-based system designed to detect potentially hazardous asteroids using Machine Learning techniques. It analyzes data from space to identify asteroids that may pose a threat to Earth. By providing early warnings, the system helps space agencies take preventive measures on time.  
The project plays a vital role in improving space safety and reducing the risk of future collisions through accurate asteroid threat assessment.

**Tools & Technologies Used**:  
- Machine Learning algorithms  
- Python and related libraries  
- Web Interface (optional if deployed)
